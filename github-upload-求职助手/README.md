# 求职助手 · Boss直聘简历岗位智能匹配插件

> 一份完整经历，千份定制简历。为每周投几十上百份简历的求职者而做。

在 Boss直聘上：**点开任意岗位 → 自动打分匹配度 → 指出你的缺口 → 一键生成为该岗位定制的简历图片 → 连同定制打招呼话术一键发给 HR**。全程不到 1 分钟。

## 为什么做这个

- 每家公司的招聘要求都不一样，认真投就得一份份改简历，改到半夜；
- 同一个岗位每家叫法不同（用户运营 / 会员经理 / 生命周期管理……），按岗位名搜索会错过大量机会。

这个插件把你的完整经历拆成「经历库」，**按能力匹配而不是按岗位名匹配**，再由 AI 从库里提炼出和当前岗位最相关的内容，生成定制简历。

## 功能

| 功能 | 说明 |
|---|---|
| 🎯 实时匹配打分 | 点开岗位自动打分（0-100），绿/黄/灰三档给投递建议 |
| 📋 硬性条件核查 | 学历、经验年限、城市逐条核对 |
| 🧩 缺口识别与补录 | 指出岗位要求但你还没录入的硬技能，对话式补录后一键重新打分 |
| 📄 AI 定制简历 | 按 Boss 简历样式生成图片简历；事实绝不编造，只做提炼与重组；支持预览/编辑/文字指令修改 |
| 🚀 一键投递 | 定制打招呼话术 + 简历图片一键发送 |
| 🔍 巡岗（可选） | 按薪资/关键词自动粗筛岗位，攒成清单流水线投递；默认关闭，内置严格频率保护 |
| 🔒 数据本地化 | 简历、经历库、API Key 全部只存在你自己的浏览器里，无任何服务器 |

## 安装

1. 点本页右侧 **Releases**，下载最新的 zip 并解压。
2. Chrome / Edge 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择 `extension` 文件夹（或 Release 包里的「求职助手」文件夹）。
4. 详细图文步骤见 [docs/安装说明.md](docs/安装说明.md)。

## 使用

1. 打开插件管理页，上传你的简历 PDF 建立经历库（或用大白话逐条录入）。
2. （推荐）在设置里填入你自己的 [DeepSeek](https://platform.deepseek.com) API Key，打分和简历质量大幅提升；不填则走本地规则版。
3. 打开 zhipin.com 正常刷岗位即可。完整说明见 [docs/使用说明.md](docs/使用说明.md)。

## 技术

原生 JavaScript 的 Chrome MV3 扩展，零框架、零构建、零后端。匹配采用两级架构：本地规则引擎（经历库技能标签即词表，免费、即时）+ DeepSeek 深度分析（用户自备 Key，结果按岗位缓存不重复计费）。简历图片用 Canvas 按 Boss 模板绘制。巡岗为独立 content script，故障隔离，内置点击间隔/单次/每小时/每日限额与验证码熔断。
