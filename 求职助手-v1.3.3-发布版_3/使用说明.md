# 求职助手 · 使用说明（小白版）

> 安装方法见「安装说明.md」。装好之后，照着下面用就行。
> 一句话理解这个工具：**你把完整经历喂给它一次，之后每个岗位它都帮你定制一份最对口的简历，一键发给 HR。**

---

## 第一步：建立你的「经历库」（只做一次，5 分钟）

经历库就是你的"完整版简历"，是所有功能的原料。建得越全，后面每一份定制简历越强。

1. 点浏览器右上角的 🧩 拼图图标，找到「求职助手」，点一下，打开管理页。
2. 进「导入」页，上传你的简历 PDF（在 Boss App 里：我的 → 我的简历 → 右上角导出，发到电脑上）。
3. 它会自动把简历拆成一条条经历，检查一遍：拆错的可以删，漏掉的手动补。
4. 没有现成简历也没关系：在「录入」页用大白话一条条写你做过的事，比如
   "在 XX 公司管过 6 个人的直播团队，一年做了 500 万流水"——写人话就行，不用像简历那样正式。

**小提示**：兼职、创业、摆摊、自媒体、帮朋友做的项目……都值得录进去。你永远不知道哪段经历会在哪个岗位上加分。

## 第二步：填 AI Key（强烈推荐，2 分钟）

不填也能用（走本地规则打分），但填了以后打分、简历、话术全部由 AI 深度定制，效果差很多倍。

1. 打开 platform.deepseek.com，用手机号注册。
2. 充值几块钱（一次分析只花几分钱，同一岗位不重复扣）。
3. 创建一个 API Key，复制。
4. 回到管理页「设置」，粘贴到 API Key 框里，保存。完成。

## 第三步：日常找工作（核心玩法）

打开 zhipin.com，像平时一样刷岗位。区别是：**每点开一个岗位，页面右侧会自动出现一个圆形分数徽章。**

1. **看分数**：点开岗位 1~3 秒后自动打分。绿色（75 分以上）值得投；黄色可以投；灰色建议把时间留给更合适的。点徽章可展开详细面板。
2. **看面板**：里面有三块——
   - 硬性条件核查：学历、经验年限、城市，一条条告诉你符不符合；
   - 能力匹配：岗位要求里你已经具备的能力（每一条都有你的真实经历支撑）；
   - 硬性缺口：岗位要求但你经历库里还没有的技能。
3. **点「⚡ 生成定制简历图片」**：AI 会从你的经历库里，挑出和这个岗位最相关的内容，按 Boss 的简历样式生成一张图片简历。
   - 放心：**公司、职位、时间、数字绝不乱编**，它只做"提炼"——把最相关的亮点排到前面，把不相关的经历改写成能体现可迁移能力的说法。
   - 觉得哪里不满意？点「✏️ 编辑」手动微调，或在输入框里用文字说"第二段经历突出带团队"，它会照改。
4. **点「发送简历并打招呼」**：插件自动帮你点开沟通、发出定制打招呼话术 + 这张简历图片。一个岗位从打开到投出，全程不到 1 分钟。

**建议先去 Boss 设置里关掉"自动打招呼语"**（我的 → 设置 → 打招呼语），否则 Boss 自己的默认招呼会先发出去一句。

## 第四步：补缺口，让分数越来越高

看到「硬性缺口」里的红色词条别慌，很多"缺口"你其实有，只是没写进经历库。

1. 点一下缺口词条（如"数据分析 +补录"），它会记入你的补录清单，词条变绿显示"✓已记入"。
2. 有空时打开管理页的「补录」页，它会像聊天一样问你："你有没有做过和数据分析相关的事？间接相关也算。"你用大白话回答，它自动整理成一条正式经历存进库。
3. 回到岗位页面，点「🔄 我已补录，重新打分」——分数和缺口立刻按你的新经历库刷新。

每补一次，你的经历库就强一分，以后所有岗位的打分和简历都跟着受益。

## 进阶：巡岗（让它帮你筛岗位）

不想一个个点岗位？打开管理页「今日匹配」：

1. 设置你的条件（期望薪资、关键词等），打开巡岗开关。
2. 之后你正常刷岗位列表时，它会在后台把看到的岗位自动粗筛一遍，高匹配的攒进「今日匹配」清单。
3. 打开清单点「开始投递」，进入流水线模式：它把每个岗位的定制简历和话术都提前备好，你只需要——看一眼、点发送、自动跳下一个。
4. 巡岗自带严格的频率保护（模拟真人节奏、每天有上限、遇到验证码自动停一天），把风控风险降到最低。默认是关闭的，不开就完全不工作。

## 数据安全

- 你的简历、经历库、API Key **只存在你自己的浏览器里**，不上传任何服务器，作者也看不到。
- 换电脑或重装浏览器之前：管理页「设置 → 数据管理 → 导出备份」，存好那个文件；新环境里「导入备份」即可原样恢复。
- 每个人的数据互相独立：你把插件分享给朋友，他看到的是他自己的空库，和你的数据毫无关系。

## 常见问题

**Q：点开岗位没出分数？**
等 2~3 秒，页面加载完会自动识别；面板会显示"正在识别页面岗位"。超过 6 秒还不行，可以把职位描述复制粘贴到面板里手动分析。

**Q：提示"AI 分析失败"？**
先检查「设置」里的 Key 有没有填对、DeepSeek 账户里还有没有余额。如果服务商换了模型名，插件会自动适配换用新模型，一般无需手动处理。

**Q：分数是不是越高越该投？**
分数是参考，不是圣旨。75 分以上优先投；50~75 分看缺口能不能补；50 分以下建议把沟通额度留给更匹配的岗位。最终判断权在你。

**Q：生成的简历会不会造假？**
不会。铁律是：公司、职位、时间、数据等硬性事实一律来自你的经历库，AI 只负责"挑重点、换说法"。你也可以在发送前预览和编辑每一个字。

**Q：会不会被 Boss 封号？**
日常的"打分 + 生成 + 发送"都是你手动点击触发的，和正常操作无异。巡岗功能有严格限速且默认关闭。到目前为止的设计原则就是安全第一，但任何第三方工具都无法 100% 承诺平台的判定，请知悉并自行斟酌。
