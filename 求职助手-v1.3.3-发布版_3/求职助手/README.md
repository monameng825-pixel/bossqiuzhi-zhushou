# AtomCV v0.7 · Boss直聘简历匹配插件

## v0.7 更新（匹配精准度大修）
- **评分公式修正，杜绝"1/1=100%"式虚高**：JD 识别出的要求少于 5 项时按 5 项算分母；只有 1 段经历命中时分数封顶 50%；要求项太少还会明确提示"分数参考意义有限"。完全不相关的岗位（如物业岗 vs 运营简历）现在会诚实显示低分或"识别不出可比对能力"
- **砍掉泛词误命中**：删除"激励""转化""团队""内容""架构""稳定性"等会到处误触发的宽泛别名，只保留具体能力词
- **薪资核查**：自动从岗位页抽取薪资，与你设置的期望薪资比对——低于期望直接红字"不建议投"，在范围内显示绿色确认（记得在管理页填期望薪资）
- **修复"发送中"卡住**：发送完成后角标变为"✅ 已发送"

## v0.6 更新（PDF 上传 + Boss 标准简历版式）
- **直接上传简历 PDF**：「导入简历」支持选择 .pdf 文件（内置 pdf.js 本地解析，不上传任何服务器），自动按视觉行还原文本再拆分——用 Boss 导出的简历实测通过
- **解析器大改**：认识 Boss 简历版式（个人优势/工作经历/内容：/业绩：/教育经历），支持 2020.02-2022.07、2011-2015、2021年3月-至今 等日期写法；**就算一个时间段都识别不出，也会按段落拆分兜底**，绝不再报"识别不出"
- **个人优势自动识别**：简历里的个人优势段落会自动存入个人信息，出现在生成的简历顶部
- **录入经历改为自由文本**：只有"经历描述"必填——技能标签自动识别、公司/时间自动从文字里抽取，其余字段全部可选
- **简历图片完全对齐 Boss 标准模版**：姓名大字 → 基本信息行（性别/生日/城市/电话/邮箱）→ 经验/求职意向/期望薪资行 → ▎个人优势 → ▎工作经历（公司+职位+右对齐时间，"内容："编号条目）→ ▎教育经历。HR 看到的就是熟悉的 Boss 简历样子
- 个人信息新增：基本信息行、期望薪资、个人优势（管理页顶部填写）

## v0.5 更新（修复真实使用反馈的四个问题）
- **新增「⬆ 导入简历」**：管理页新页签，把你的完整简历全文粘进去（Word/PDF 里全选复制即可，也支持 .txt/.md 文件）→ 自动按时间段拆成经历卡片、自动打技能标签 → 预览确认后一键入库，**同时自动清除演示示例数据**
- **修复简历发两遍**：待发任务"领取即销毁"+执行锁，页面刷新/URL变化不会再触发第二次
- **招呼语发送增强**：适配 Boss 聊天输入框（contenteditable），发送后校验是否真的发出；没发出会明确告诉你"已填入输入框请按回车"或"已复制请粘贴"，不再静默失败。注意：**Boss 自己的默认招呼语一定会先发**（平台行为，拦不住）——想只发定制版，在 Boss「消息设置-招呼语」里关闭默认招呼即可
- **示例数据醒目警告**：只要你还在用演示示例库或没设置姓名，岗位页侧栏和简历生成页都会显示黄色警告并可一键跳转设置，避免把假简历发出去

## 首次使用（3 步，5 分钟）
1. 管理页顶部：填**姓名**和一句话头衔（简历图片的抬头）
2. 「⬆ 导入简历」：粘贴你的完整简历 → 解析 → 存入（示例数据自动清除）
3. 「经历库」：检查每张卡片的技能标签，补充缺的——标签越准，匹配分越准

## v0.4 更新：一键沟通并发送（岗位页直达聊天全链路）
- **岗位页生成简历图片后，下方出现可编辑的招呼语**（默认模板可在管理页设置，支持 {岗位} {公司} {能力} 占位符）
- **新按钮「🚀 一键沟通并发送」**：插件替你点「立即沟通」→ 自动点弹窗里的「继续沟通」进入聊天 → **自动发出招呼语文字 + 把简历图片放入发送通道**（图片如弹出预览，点一下确认即可）。全程一次点击
- 每步都有状态反馈；任何一步自动失败都会降级为"已复制，请手动粘贴"，不会卡死
- 看板状态自动推进为「已招呼」
- 修复：岗位名误抓成 HR 姓名（如"赵女士"）的 bug，现在会过滤人名并从页面标题兜底
- 安全边界不变：只处理你当前正在看的这一个岗位，由你手动触发，无批量、无后台自动投递

## v0.3 更新（流程改直线，回应真实使用反馈）
- **岗位页流程只剩两步**：看分 → 点「生成定制简历图片」直接出图（Boss 风格简历模版，按公司分组排版）。删除了文字预览、暂存到看板、复制招呼语这些多余步骤
- **图片下方可勾选调整**：点掉不想放进简历的经历，自动重新生成
- **看板自动记录**：生成即入看板（状态"想投"），不需要手动存
- **跨页面接续（修复"点进聊天后失忆"）**：生成的简历自动持久化。你在岗位页生成后点「立即沟通」（Boss 自动发默认招呼语）→ 进入聊天页 → 点右侧 AtomCV 角标，**刚才那份简历就在那里等你**，一键「发进聊天」
- 聊天页也保留：换岗位重新生成 / 粘贴 JD 生成

## v0.2 更新
- **任何行业都能打分**：你经历库里的技能标签本身就是匹配词表（Java/MySQL/用户增长…直接在 JD 里比对），不再受内置词表领域限制
- **适配 Boss 真实页面**：左列表右详情的双栏结构；同一 URL 下点左侧切换岗位也会自动重新打分
- **图片版定制简历**：预览页新增「🖼 简历图片」——生成图片版（含你的姓名/头衔，在管理页设置），可复制（聊天框 Ctrl/Cmd+V 直接发）、可下载
- **聊天页模式**：在 Boss 消息页，角标变为 📄——选择这个聊天对应的岗位（或粘贴 JD）→ 生成简历图片 → 点「发进聊天」自动放入发送框，你在页面上确认发送即可
- 识别不出能力时诚实提示原因，而不是误报"没有 JD"

你的经历库，一次维护，双向复用。装在 Chrome 里，长在 Boss直聘岗位页上。

## 安装（1 分钟）

1. 解压这个文件夹到任意位置
2. 打开 Chrome，地址栏输入 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选择解压出的 `ext` 文件夹
5. 完成。插件已预置一套示例经历库（运营/增长方向），可直接体验

## 使用

**日常投递（每次 60 秒）**
打开任意 Boss直聘 岗位详情页 → 页面右侧出现匹配分角标（绿≥75 值得投 / 黄 50–74 / 灰<50 谨慎投）→ 点角标展开侧栏：
- 诊断卡：总分、已覆盖能力（每项都有你的真实经历支撑）、缺口（点击可记入补录清单，**不会**往简历里塞你没有的东西）
- 「生成定制简历」：从经历库抽取相关经历组装，每条 bullet 可点「溯源」看原始记录
- 招呼语：自动生成、可编辑，点「复制并记录投递」→ 去聊天框粘贴发送
- 一切自动记入看板，并显示今日已招呼 n/150（Boss 每日上限）

**建你自己的库（第一次，10 分钟）**
点浏览器工具栏的 AtomCV 图标打开管理页 → 「清空经历库」删掉示例 → 在「＋录入经历」里用大白话写你的每段经历 + 技能标签。写得越全，匹配越准。

**看板**：记录每个岗位的匹配分、状态（想投/已招呼/已回复/面试/Offer）、回复率统计。

**补录清单**：在岗位页点过的缺口能力都在这里——每条都是一次补库机会。

## v0.1 的边界（下一版要做的）

- 匹配是「规范能力表 + 别名规则」，还不是向量语义匹配 → 下一版接 embedding
- 录入需手动填技能标签 → 下一版接 LLM 自动拆分原子+打标（导入 PDF 简历一键建库）
- 招呼语是模板生成 → 下一版接 LLM（用户自带 API key）
- 简历输出是文本预览 → 下一版生成图片版/PDF 版供聊天发送
- 数据全存在本地浏览器（chrome.storage），不上传任何服务器
