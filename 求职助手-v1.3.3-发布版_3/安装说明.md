# 求职助手 · 安装与使用说明

## 这是什么
一个 Boss直聘 浏览器插件：打开任意岗位自动打分匹配度、指出你的缺口、
一键生成为该岗位定制的简历图片，并连同定制打招呼话术一键发给 HR。
你的所有数据（简历、经历库、API Key）只保存在你自己的浏览器里，不上传任何服务器。

## 安装（3 分钟，只需一次）
1. 解压这个压缩包，把「求职助手」文件夹放到一个不会误删的位置（例如 文档 目录）。
2. 打开 Chrome / Edge 浏览器，地址栏输入 chrome://extensions 回车
   （Edge 输入 edge://extensions）。
3. 打开右上角（Edge 在左侧）的「开发者模式」开关。
4. 点「加载已解压的扩展程序」，选择第 1 步解压出的「求职助手」文件夹。
5. 完成。打开 zhipin.com 任意岗位页，右侧会出现匹配分圆形徽章。

## 首次使用（重要）
1. 点浏览器右上角的插件图标，打开「求职助手」管理页。
2. 在「导入」页上传你的完整简历（支持 Boss 导出的 PDF），建立你的经历库。
3. （推荐）在「设置」页填入你自己的 DeepSeek API Key（在 platform.deepseek.com
   注册后创建，几块钱能用很久），匹配打分和简历生成会精准得多。
   不填 Key 也能用，走本地规则打分。

## 常见问题
- 打不出分？刷新页面等 2 秒；插件会自动重试识别。
- 会不会被平台风控？插件默认只在你主动点击时工作；巡岗功能默认关闭，
  开启后也有严格的频率限制（模拟真人节奏），风险已降到最低，但请自行斟酌使用。
- 换电脑/重装浏览器前，先在管理页「设置 → 数据管理」导出备份。
